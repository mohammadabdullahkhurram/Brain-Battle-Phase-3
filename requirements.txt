# Brain Battle — pinned Python dependencies.

# This is the pinned lockfile; pyproject.toml declares the same dependencies
# abstractly (lower bounds) and the package metadata. Derived from the actual
# `import` statements across the repo (grepped, not copied from an old pip
# line) and pinned to the versions this environment's tests/ suite passed
# against. matplotlib and pyqtgraph are intentionally absent — every plot in the
# app (including the EEG viewer) is drawn with Qt's own painter. Only the
# ffmpeg *binary* is called (via subprocess); there is no ffmpeg Python package.
#
# One more runtime dependency is NOT here because it is a system install, not
# a pip package:
#   ffmpeg — export encoding + probing (brew install ffmpeg)
# Review & Label playback uses PyAV (`av`), which bundles its own ffmpeg libs,
# so there is no longer any VLC / python-vlc desktop dependency.
#
